# Modo ao vivo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** botão "Ao vivo" na seção "Telemetria atual" do Painel da máquina: a placa passa a mandar telemetria a cada 2 s e a seção mostra números, faixa de alerta e um terminal com "✓ gravado · chegou em X s" (Issue #2).

**Architecture:** o estado fica no banco (`equipamentos.ao_vivo_ate`). A placa descobre o intervalo na resposta de `registrar_dispositivo` (`telemetria_ms`). O painel liga/desliga por `POST /equipamentos/<id>/ao-vivo` e, ligado, consulta `GET /ao-vivo` a cada 2 s. Sem WebSocket/Realtime.

**Tech Stack:** PostgreSQL (Supabase; testes em PGlite/Node), C++ Arduino (ESP32), Python 3.14 + Flask, HTML/JS puro, pytest + Playwright.

**Spec:** `docs/superpowers/specs/2026-10-06-ao-vivo-design.md` · **Mockup aprovado:** `docs/superpowers/specs/2026-10-06-ao-vivo-mockup.html` (abrir no navegador; é a referência visual — animações, cores, tamanhos).

## Global Constraints

- Escopo só **furto e incêndio**; não sugerir colisão, distância, clima.
- Intervalos: ligado **2000 ms**, normal **10000 ms**; ligar dura **2 h**; painel consulta a cada **2 s**.
- `GET /ao-vivo`: `desde` no máximo **10 min** no passado, até **5 s** no futuro; sem `desde` → últimos **30 s**; no máximo **30** itens por lista.
- Escape vermelho a partir de **450 °C** (`TEMP_ESCAPE_ATENCAO` do firmware).
- Nada de script/CDN novo (CSP em `api/app.py` `_CSP`). CSS novo vai no `<style>` do `index.html` (classes `av-*`), sem rebuild do Tailwind.
- Commits pequenos, em português, mensagem gravada em arquivo **sem BOM**: `[IO.File]::WriteAllText($m, $texto, (New-Object Text.UTF8Encoding $false)); git commit -F $m`. Cada commit termina com `Refs #2`.
- Nunca commitar `api/.env` nem `firmware/sompo_hardware_final/segredos.h`.
- PowerShell 5.1: sem `&&`; encadear com `;` ou `if ($?) { }`.
- Python dos testes (o worktree não tem venv): `$PY = "$HOME\OneDrive - Fiap-Faculdade de Informática e Administração Paulista\FIAP\SOMPO\sompo-sprint3\.venv\Scripts\python.exe"`; rodar de dentro de `api\`: `& $PY -m pytest -q tests\<arquivo>`.
- Playwright: rodar só os arquivos do bloco tocado (a suíte inteira pesa); a suíte completa é da tarefa 6.
- Estilo do arquivo vizinho: comentários de código em português sem acento; textos de UI com acento.

## Review Focus

1. `desde` com `+00:00` sem `encodeURIComponent` chega como espaço → o servidor aceita (troca espaço por `+`), não responde 400. (teste na Tarefa 4)
2. Relógio do ESP32 sem NTP ou adiantado: `recebido_em − ocorrido_em` negativo ou enorme → a linha mostra só "✓ gravado", nunca latência inventada. (teste na Tarefa 5)
3. Linha confirmada (commit) depois do instante do cursor: o cursor recua até 5 s e o painel descarta repetidas por `registro_id` → nada some e nada aparece duas vezes. (testes nas Tarefas 4 e 5)
4. Painel ligado com a placa parada por mais de 10 min: o cursor nunca envelhece e o `GET /ao-vivo` nunca começa a dar 400. (teste na Tarefa 4)
5. Servidor manda `telemetria_ms` estranho (0, 1, 500, texto) → a placa fica em 10 s. (teste na Tarefa 2)

```python
JANELA_PADRAO = timedelta(seconds=30)
JANELA_MAX = timedelta(minutes=10)
FOLGA_FUTURO = timedelta(seconds=5)
RECUO_CURSOR = timedelta(seconds=5)   # linha confirmada (commit) um pouco depois do instante do cursor
LIMITE = 30
COLUNAS = {
    'telemetria': 'registro_id,equipamento_id,criado_em,ocorrido_em,recebido_em,temp_escape,temp_ambiente,umidade_ar,'
                  'chama_detectada,vibracao,motor_ligado,capo_aberto,tanque_aberto,operador_autorizado,nivel_risco,'
                  'operador_id,uid',
    'eventos': 'registro_id,equipamento_id,criado_em,ocorrido_em,recebido_em,tipo,severidade,temp_escape,operador_id',
    'registros_operacao': 'registro_id,equipamento_id,ocorrido_em,recebido_em,tipo,motivo,uid,operador_id,sessao_id',
}


def _instante(texto):
    return datetime.fromisoformat(texto.strip().replace(' ', '+').replace('Z', '+00:00'))


def _desde(texto, agora):
    if not texto:
        return agora - JANELA_PADRAO
    try:
        # '+' do fuso chega como espaco quando o cliente nao codifica a URL.
        t = _instante(texto)
    except ValueError:
        raise frota.FrotaErro('desde_invalido')
    if t.tzinfo is None or t > agora + FOLGA_FUTURO or t < agora - JANELA_MAX:
        raise frota.FrotaErro('desde_invalido')
    return t


def _depois(tabela, equipamento_id, desde):
    # As 30 mais novas (desc), devolvidas em ordem crescente para o terminal.
    rows = db.consultar_tabela(tabela, filtros={'equipamento_id': f'eq.{equipamento_id}',
                                                'recebido_em': f'gt.{desde.isoformat()}'},
                               select=COLUNAS[tabela], order='recebido_em.desc', limite=LIMITE)
    return list(reversed(rows))


@bp.get('/ao-vivo')
def ao_vivo():
    frota.resolver_equipamento()
    eq = getattr(g, 'equipamento', None)
    if not eq:   # Sompo consultando ID legado sem maquina: o ao vivo e por maquina
        raise frota.FrotaErro('equipamento_obrigatorio')
    agora = datetime.now(timezone.utc)
    desde = _desde(request.args.get('desde'), agora)
    telemetria = frota.identificar_registros(_depois('telemetria', eq['id_equipamento'], desde))
    eventos = _depois('eventos', eq['id_equipamento'], desde)
    operacoes = frota.identificar_registros(_depois('registros_operacao', eq['id_equipamento'], desde))
    recebidos = [_instante(r['recebido_em']) for r in (*telemetria, *eventos, *operacoes) if r.get('recebido_em')]
    cursor = max([agora - RECUO_CURSOR, *recebidos])
    resposta = jsonify(telemetria=telemetria, eventos=eventos, operacoes=operacoes,
                       ao_vivo_ate=eq.get('ao_vivo_ate'), cursor=cursor.isoformat(), agora=agora.isoformat())
    resposta.headers['Cache-Control'] = 'no-store'
    return resposta
```

function resumoLeitura(t){
